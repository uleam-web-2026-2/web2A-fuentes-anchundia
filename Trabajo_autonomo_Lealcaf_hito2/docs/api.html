Autenticación

Inicio de sesión de las cuentas de prueba.

Iniciar sesión

Pública. Verifica usuario y contraseña de la cuenta; devuelve un JWT de una hora. No existe registro ni CRUD de cuentas. La cuenta cliente demo está asociada a un cliente dedicado cuyo ID puede ser distinto de 1.

Request Body schema: application/json
required
usuario
required
string [ 1 .. 100 ] characters
password
required
string <password> [ 1 .. 72 ] characters

Responses

Canjes

Solicitud, consulta y máquina de estados de Canje.

Solicitar recompensa

Cliente autenticado. Recibe únicamente recompensa_id y sucursal_id; el cliente proviene del JWT. El ID, fecha, puntos y estado inicial solicitado los decide el servidor. Los campos adicionales no se trasladan al dominio. Solicitar no descuenta puntos; se comprueban y descuentan al confirmar.

Confirmar o cancelar un canje

Solo administrador. Permite solicitado a confirmado o cancelado. Confirmar bloquea el cliente, vuelve a comprobar el saldo y guarda estado y movimiento negativo en una única transacción. Si falla la escritura del movimiento se revierte el estado. Una transición desde un estado final devuelve 422. Destino desconocido devuelve 400.

Authorizations:
bearerAuth
path Parameters
id
required
integer >= 1
Example: 1

Identificador entero positivo del recurso.

Request Body schema: application/json
required
estado
required
string
Enum: "solicitado" "confirmado" "cancelado"

confirmado o cancelado son destinos válidos desde solicitado. solicitado es un valor conocido, pero no es destino permitido y devuelve 422. Un valor desconocido devuelve 400.

Responses

Servidor local; localhost:8080 apunta a la misma interfaz.
